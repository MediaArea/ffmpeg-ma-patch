FFmpeg - Vulkan support on macOS
=====================================================

This build of FFmpeg includes a Vulkan loader and the KosmicKrisp Vulkan
driver. No Vulkan SDK, Homebrew package or environment variable is required.

KosmicKrisp is implemented on top of Metal 4 and requires:

 * An Apple Silicon (arm64) Mac.
 * macOS 26 or newer.

The runtime is stored next to the binaries in lib/ffmpeg-ma/lib. The ffmpeg,
ffprobe and ffplay executables automatically point VK_DRIVER_FILES to this
runtime.

Checking the installation
-------------------------

From the extracted archive directory, the following command should list the
Vulkan device(s) found and exit without error:

        bin/ffmpeg -v verbose -init_hw_device vulkan -f lavfi -i nullsrc -frames:v 1 -f null -

If the error "Unable to open the libvulkan library!" is displayed, the archive
is incomplete. If no device is found, the macOS version or the hardware is unsupported.
